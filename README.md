# Movie Recommender System

A movie recommender system built using content-based filtering.
It recommends movies based on similarity of genres, cast and keywords.

## Tech Used
- Python, Scikit-learn, Flask
- TF-IDF vectorization and cosine similarity

## How to Run
1. Clone the repo
2. Install requirement: pip install -r requirements.txt
3. Run: python app.py
4. Open browser at localhost:5000
